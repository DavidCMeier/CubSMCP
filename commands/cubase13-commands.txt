# Cubase 13 key command catalog: the commands the bridge script binds.
# Category headers are written as [Category]; lines starting with # are comments.
# Names are Cubase internal names (the snippet of each entry in the MIDI Remote README "List of Commands"),
# not the labels shown on screen: page.makeCommandBinding ignores a label without any error.
# The on-screen labels come from commands/cubase13-internal-names.json (npm run extract:commands) and work as aliases.
# Score, ADM, head tracking, VR player, game audio and MediaBay inspector categories are omitted on purpose; of Media only
# the browsers, the preview and the insert commands are bound. cubase_list_commands with includeUnbound lists the rest.
# Add your own macros / Logical Editor presets in commands/user-commands.txt using the same format.
